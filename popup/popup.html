About & Privacy

Field Inspector reads only the HTML of the page you're currently viewing, entirely inside your browser. It never sends page content, field values, or browsing activity to any server, and it never modifies form data — clicking a field only opens a read-only info panel.

Permissions used:

  • activeTab / scripting — inject the inspector only into the tab you explicitly enable it on.
  • storage — remember your preferences (this popup's settings) locally in your browser.

No host permissions are requested, so the extension cannot run in the background on sites you haven't activated it on.
