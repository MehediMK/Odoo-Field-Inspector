About & Privacy

Field Inspector reads only the HTML of the page you're currently viewing, entirely inside your browser. It never modifies form data — clicking a field only opens a read-only info panel.

Odoo Developer Mode is the one exception to "nothing ever leaves your browser": when it's on and a clicked field is recognized as an Odoo field, the field's model + technical name (never its value) are sent to the same Odoo server you're already logged into, to fetch that field's real definition. Turn it off above to disable this entirely — everything else keeps working.

Permissions used:

  • activeTab / scripting — inject the inspector only into the tab you explicitly enable it on.
  • storage — remember your preferences (this popup's settings) locally in your browser.

No host permissions are requested, so the extension cannot run in the background on sites you haven't activated it on.
